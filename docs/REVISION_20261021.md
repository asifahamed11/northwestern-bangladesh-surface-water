## Reproduce

After installing the existing requirements, from the repository root:

```powershell
python code/reproduce_joint_pilot.py --output reproduced/joint_pilot
python code/reproduce_figures.py --output reproduced/figures
```

Use fresh output folders. The pilot command audits the eight original CSVs against their frozen comparator exports, recomputes four tables, and compares them with the delivered tables. It needs no Earth Engine login or new download. The figure command reproduces Figures 3, 4, 5, 8 and 12; Figure 8D now shows the completed pilot class comparisons. Its other panels retain the ten-year seasonal support and selected score probes. The assisted class-cell CSV remains available.

Files are in `data/revision/batch_completion_20261021/`. `batch_task_status_completed.json` records the authenticated task observations and download incidents. The October 20 delivery and its pending-status record are historical snapshots and are preserved. Annual trend tables and active labels were not changed by this completion.
