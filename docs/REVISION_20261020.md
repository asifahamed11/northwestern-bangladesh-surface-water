## Reproduce

Use Python 3.12 and code/requirements-dev.txt, then run from the repository root:

```powershell
python code/reproduce_revision.py --output reproduced/revision_results
python code/reproduce_figures.py --output reproduced/revision_figures
```

The first command refits annual models and window/matched-month summaries from genuine derived inputs. Eleven tables are compared using 1e-8 relative and 1e-10 absolute tolerances. The second redraws Figures 3, 4, 5, 8 and 12 and compares pixels. Both preserve originals and create no missing observations or reference labels.

The files in code/revision/upstream_workspace retain original workspace paths for provenance. Actual raw re-execution requires the original raster/crop archive and folder layout; these files are not advertised as standalone replays. The pending Earth Engine quarter jobs must not be submitted again while already queued.

The original fifteen-table replay remains code/reproduce_reported_results.py. The historical Figures 1/3/5 replay is code/reproduce_figures_v020.py, with original targets in provenance/legacy_figures.
